Starship - A Upcoming Animated Wallpaper App built with Python.

Starship is completely free and open-source while staying minimalist and requesting no donations.
Starship is expected to release within this week around 18th Sep to 20th Sep.

The Official DMG File will be released soon.

To use Starship, You require a mp4 file or similar for a wallpaper, You can import your own wallpaper as Starship does not have a gallery.
